Site manager

Products

Edit product details, assign an image for each surface finish, and add up to 3 detail close-up images that appear directly under the main product photo. The Series field decides which family a product belongs to; Type is the faucet kind printed on the card and used by the product-page filter. Select a file from your computer to preview it; the file is included when you export the update package.

How this works: this page runs entirely in your browser and does not connect to a server. Your edits stay here until you export and upload the update package. Nothing is published by accident. Each product shows at most 3 detail views — extra slots are ignored. Use square close-ups (handle, spout, finish texture); WebP or JPG under 300 KB each keeps the site fast.

Series

The website groups products by series. One series can hold basin mixers, kitchen faucets, shower and bathtub mixers, concealed shower valves and shower column sets — each with its own finishes and up to 3 detail photos.

One catalogue page = one series. Set the catalogue page number here and visitors get a direct link to that page in the PDF. Give every product the same Series name and choose its Type on the Products tab. The quickest way to add a whole series is to send your assistant one folder of images per series: the import script creates the series, the products and the image paths automatically. The 2026 catalogue has also been imported page by page: each page is its own series with a full-page cover and a collapsible photo gallery of every image on that page.

Catalogs & files

Register your PDF catalogs here, or drop any product images and PDFs into the bulk area below to add them to the update package without editing a single line of data.

Keep individual PDFs under 25 MB (the Cloudflare Pages per-file limit). Compress images to WebP before uploading so the site stays fast on mobile networks.

Bulk upload files

Drop product images and PDF catalogs here or click to choose files. Images go to assets/img/, PDFs go to assets/catalogs/.

Company info

Company details, products and catalogue files are managed here. Export an update package whenever you change something.

The email field is used by every "Inquire" button and the contact form. Set it to a real mailbox on your own domain.
The whatsapp field is digits only in international format, with no + or spaces (e.g. 8613586626316). One edit updates the floating chat button, the contact page, and the per-product WhatsApp quotation buttons everywhere.

Export update

Download a single ZIP containing the updated data files plus every image and PDF you selected. Upload it to your GitHub repository and the website refreshes automatically in about a minute.

Do not skip this step. Edits made on this page are local to this browser tab. Closing the tab without exporting loses them.

Steps 1–5 are done; the notes below are kept as setup reference.
    1

    Domain registered and hosted on Cloudflare — done

    grifowheatstraw.com is registered and delegated to Cloudflare, so no nameserver change is needed. Keep auto-renew and registrar lock enabled, and watch the renewal price rather than any first-year promotion. Keep the registrant in your company name.

    2

    Create a free GitHub repository

    Upload this entire independent-site folder as a new repository (private is fine). GitHub's web uploader accepts dragged folders, so no command line or Git install is needed.

    3

    Connect Cloudflare Pages

    In the Cloudflare dashboard: Workers & Pages → Create → Pages → Connect to Git → pick the repository. Build settings: framework None, build command (leave empty), output directory /. Deploy. You get a free *.pages.dev address, unlimited bandwidth and automatic HTTPS.

    4

    Bind grifowheatstraw.com to Pages

    In Pages → Custom domains, add grifowheatstraw.com and www.grifowheatstraw.com. The zone is already on Cloudflare, so Pages creates the CNAME records and issues the SSL certificate automatically — do not add A records by hand. Hosted outside mainland China with no mainland customers, so no ICP filing is required.

    5

    Set up a free business email address — done

    Done. Cloudflare dashboard → Compute > Email Service > Email Routing: (1) Destination Addresses → Jackbathroom@aliyun.com verified; (2) Routing Rules → sales@ and info@ → Send to an email → verified destination; (3) Catch-all enabled so misspelled addresses still arrive. Unlimited inbound mail, CNY 0. A test message was received before the site email was switched. Note: Email Routing only receives and forwards; to send from @grifowheatstraw.com you need a real mailbox (Zoho Mail free plan or similar), which requires switching MX away from Cloudflare — one domain can only have one MX set, so choose one, not both.

    6

    Routine updates

    Send new product images and PDF catalogs to your assistant: files go into inbox/, the import script rebuilds data/ and assets/, and the site is republished. For detail close-ups, name the files 型号_detail1.jpg, 型号_detail2.jpg, 型号_detail3.jpg (or 型号_细节1.jpg) — up to 3 per model, shown under the main photo. For a whole series, put all of its photos in one folder named after the series: inbox/VIENNA/SS504002_Chrome.jpg, inbox/VIENNA/Kitchen Faucet_Chrome.jpg, and so on. One folder = one series = one catalogue page. Type names can be Chinese (面盆龙头 / 厨房龙头 / 淋浴龙头 / 浴缸龙头 / 暗装淋浴龙头 / 花洒升降套装). Every page of the PDF catalogue is also imported as its own series, so nothing in the catalogue is missing from the site. Add a series.json in the folder for a custom description and page number, or just let the import script sort it out. You can also use this Site manager → Export update → unzip → drag the folders into the repository root on github.com → Commit. Pages rebuilds automatically. No server, no deploy command, no fee.

    Limits to keep in mind

    • Cloudflare Pages: 20,000 files per site, 25 MB per file, 500 builds per month. Far more than a product-showcase site needs.
    • No server-side code, no database, no shopping cart. Inquiries arrive by email or WhatsApp, which is normal for B2B sanitary ware.
    • This manager edits files locally in the browser. It is not a hosted CMS and cannot push changes by itself.
    • Do not put prices, cost sheets or customer lists in a public repository. Keep the repository private if the files are sensitive.

    When to upgrade

    Move to Cloudflare R2 + Workers only when a single catalog exceeds 25 MB, total assets exceed a few GB, or you need a real browser-based upload that publishes instantly without touching GitHub. R2 has a permanent free tier of 10 GB with zero egress fees, but it requires a small Worker for authenticated uploads and a site refactor. Until then, the Pages + GitHub setup is both cheaper in effort and free in cash.
